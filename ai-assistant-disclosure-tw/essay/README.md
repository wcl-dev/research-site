## v1 → v3 之間撤回了什麼

一併記錄，以免舊稿被誤讀：

- **「AI 已成為民主社會的總編輯」** → 降級為「AI 助理正在成為重要但不透明的資訊中介」。無任何使用率、信任度或認知影響的實證支持較強的版本。
- **「偏差烙在權重／訓練」** → 撤回。關閉搜尋後行為仍在，只能支持「該輸出不需要產品的可見搜尋功能」，不足以指向訓練成因。
- **「格式不是瓶頸」** → 撤回。未進行格式對照實驗，不能排除該因素，亦不足以據此排列政策優先順序。

探針本身另有三項宣稱在重複與跨產地對照後被撤回，詳見 `../pipeline/probe/findings.md`。
