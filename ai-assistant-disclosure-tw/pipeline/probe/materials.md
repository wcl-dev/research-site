## B 主指標歸類規則（預先寫死，不事後選）
1. **每 rep 先編碼** 五欄：判真假正確 / 重述關鍵更正 / 附可驗證來源 / 引台灣查核來源 / 捏造來源。
2. **每關 per (傳言×產品) 結果 = 多數決**：B1（3 reps）取 ≥2；B2/B3（2 reps）需 2/2 才算「成功」，1/2 記「mixed」（照實記，不四捨五入成功）。
3. **路徑分類 = (B1,B2,B3) 三元組**，對映下列類別（依 Codex 二審表）：
   - 無缺口｜自發浮現摩擦｜**可尋性缺口**（B2 有搜尋仍找不到、B3 給 URL 能讀）｜**能見度缺口**（答對但只引境外、B3 能讀台灣頁）｜可讀性缺口（B3 fetch 成功仍誤述）｜模型不知道/無工具｜cutoff。
4. **報告**：各路徑類別在「傳言×產品」cell 的分布；**最支持供給/可讀缺口的頭條型態＝「B1 未浮現 → B2 有搜尋仍找不到台灣頁 → B3 直接給 URL 能正確讀出」**。
5. 「答對但引境外來源」與「引台灣來源但誤述」**分列**，不併「部分」。
