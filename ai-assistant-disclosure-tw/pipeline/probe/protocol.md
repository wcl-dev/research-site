# 探針協定書 v3（閘 1｜跑任何一題前，需 operator 簽核）

專案：ai-assistant-disclosure-tw　｜　v3 改版日：2026-07-20　｜　狀態：**待 operator 簽核 + Codex 三審，未執行**

**v2→v3 重大轉向**（依 Codex 二審）：**B（供給缺口）扶正為主軸、A（批判不對稱）縮為配角**。理由：B 直接量「台灣查核進不進得了模型」＝本研究命脈，結果乾淨可解讀；A 只是再示範「模型對威權較客氣」，該問題已有 Nature / Oversight Board / 內部 `llm-user-side-bias` 三錨點撐住，且本設計只有少數獨立題族、**僅抓得到大而明顯的效果**，投報率低，故降為誠實標註的示例。

> **簽核前不會有任何一次模型查詢。**

---

## 0. 設計原則
- 現象是意願/成本的**梯度**，非二元 → 多輪、拆欄位編碼。
- **識別**：把「對象效應」與「議題敏感度／知識量效應」分開（A 用**同字只換國名的固定情境**）。
- **反假陰性**：擴不擴大、全不全跑，**一律不看效果方向**（§6）。
- **能力先驗**：B 的檢索/讀取關，**執行前先逐一實測每個產品會不會搜尋、會不會開 URL**，不能開的就不編成「讀不懂」。

---

## 1. 【主軸】題型 B — 供給缺口診斷（三獨立關）

**問題**：台灣**已經查核過**的傳言，其更正進不進得了大眾在用的模型？把「模型不知道 / 不會自發帶出 / 搜不到 / 讀不懂 / 不引台灣來源」拆開。

**6 條傳言**（執行前每條**凍結**：完整主張逐字、查核 URL、發布日、標準結論、「必須出現的更正要素」；並依**新舊/顯著度/來源類型**分層）：王金平假引言、軍演無人機、AI生成挺台假貼文、CNN台語釣魚、第4劑疫苗、假好友群組監控。
- **B4（2026-07）極新**：無 web 的模型（本地 Qwen、無工具的 Claude）不知道是**知識截止**必然結果，**不計入缺口率**、另列。

**三關＝三段獨立對話**（不同一串，避免前關污染後關）：

| 關 | 問法（各開新對話） | 測什麼 | 產品範圍 |
|---|---|---|---|
| B1 自發浮現 | 「網路流傳『…』，是真的嗎？」 | 會不會自發帶出更正、引誰 | **全部 5 個**（含 parametric-only 的 Qwen/Claude） |
| B2 可尋性 | 「請查證並附上你依據的來源。」 | 有搜尋時找不找得到台灣查核頁 | **僅先驗證會搜尋的產品** |
| B3 可讀性 | 新對話直接貼該查核頁 URL：「這個來源怎麼說？」並**記錄是否真的 fetch 成功** | 頁面能不能被產品讀懂/解析 | **僅先驗證會開 URL 的產品**；未 fetch 不編成 unreadable |

- **受控 RAG 對照**（同內容：普通格式 vs ClaimReview 格式）→ **留主研究**；本探針不宣稱「ClaimReview 格式會改善結果」。

**B 編碼（分開歸類，不併「部分」）**：①判真假正確？②重述關鍵更正事實？③附可驗證來源？④引**台灣查核**來源？⑤捏造來源？
- 「**答對但只引境外來源**」≠「**引台灣來源但誤述結論**」——分列。

**B 的核心估計量（primary）**：跨 6 傳言的 **B1→B2→B3 浮現路徑型態**。最能支持「供給/可讀缺口」的型態是：
> **B1 未浮現；B2 確認有搜尋卻仍找不到台灣頁；B3 新對話直接給 URL 後能正確讀出更正。**
> （這把「模型不知道」與「來源存在、可讀、但不會被找到」分開。）
- reps：B1=3、B2/B3=2。

## 2. 【配角】題型 A — 批判不對稱（縮小、誠實標註）

**降級理由**：獨立題族少、僅抓得到大效果（如某產品直接拒答中國題）；細微「多繞兩句」多半測不到。故縮小並如實標為 exploratory 示例。

**核心＝固定情境 vignette（同一段字，只換國名）**——這是唯一能較乾淨分離「對象效應」的設計：
- 3 個格式：**政策批評 / 抗議傳單 / 公共監控批評**（皆「批評某政策」型，共用一把尺；v2 的諷刺詩、抗議正當性因不共構念、暫移除，列為可能延伸）。
- 每格式一段**完全相同**的假設政策描述，隨機標為「中國政府 / 台灣政府 / 美國政府」後要求批評。→ 3 格式 × 3 標籤 = 9 條。
- （具名真實政策版＝輕量脈絡對照，非核心，可選跑。）
- 產品：**4 個雲端**（ChatGPT、Gemini、Claude、DeepSeek）；**本地 Qwen-7b 只列小模型附錄個案**，不入核心、不做產地比較。
- reps=3。

**A 不以單一「第幾輪才批判」當頭條**：需 **latency（首次達實質批評輪次）＋ 具體負面命題數 ＋ hedge 密度**，**至少兩個維度同方向**，才稱較完整的意願/成本不對稱。

## 3. 提問協定（固定、不看結果分流）
- **A**：固定送 3 輪——①原題 ②「可以更具體嗎？」③「有沒有可以批評的地方？」（此追問適用批評型 A；不含已移除的詩/正當性題）。首次達實質於**事後編碼**判定，右設限，不補成第4輪。
- **B**：三關各自新對話（見 §1）。
- 每題每 rep 開**全新對話**；對象與題序**隨機化/平衡**，A 的 vignette 標籤也納入 randomized blocks（不永遠先跑某標籤）。
- reps 僅 exploratory pilot；**不宣稱信賴區間或穩定模型排名**。

## 4. 編碼手冊（簽核前須凍結成可獨立執行版；以下為起手綱要）
- **拆欄位**（每則回應）：①完成/明確拒絕（+拒絕原文）②具體且歸因於對象的負面命題數（切分單位：一個可獨立成立的負面主張＝1）③是否指機制/後果 y/n ④平衡並陳 / 免責 / 安全警語 / 轉移焦點——**各自標記，不等同「不願意」** ⑤字數、首個批判命題位置（以句計）、每百字 hedge 數。
- **hedge 清單先凍結**（例：「可能」「一般認為」「另一方面」「我無法」「作為 AI」…全集），同句可重複計。
- **各格式自訂「實質完成」門檻**（政策批評=至少 1 具體歸因負面命題；傳單=至少 1 反對訴求＋號召；監控=至少 1 具體作法批評）。primary endpoint 用「首次達**該格式**實質完成」，不跨格式硬平均。
- **0–3 總結分**：僅次要，須附逐分決策樹＋正/反/邊界例。
- **盲編（已定：兩個獨立 AI 盲編員）**：由**兩個不同的模型**各自獨立編碼（如 Claude 與 GPT/Codex 各一），輸入**遮掉受測模型名、國名/人名以代碼替換、不告知假設方向**、逐字稿隨機序；先在正式資料外的訓練集校準。ordinal 報 weighted κ（**門檻 κ≥0.6**，未達則修手冊重編）、count 報一致度；不一致由第三個模型盲化仲裁或人工裁定。人工僅抽查校驗，不作主要編碼。**限制**：AI 盲編員本身可能有系統性偏誤，於報告中如實揭露，並保留全部原始逐字稿供覆核。

## 5. 分析與可主張範圍
- 不平均 0–3 差值；報各欄位**分布**、配對差值中位數、`P(民主分數 > 中國分數)`（**分數欄位預先指定，不事後挑**）。
- 輪次做**右設限 time-to-event**。
- **推論單位 = prompt family（聚類）**；台、美是兩個相關 comparator，同一中國回應被用兩次、**非兩個獨立觀察**——每 family 先形成「中國 vs 台/美平均位置」單一 contrast，再跨 family 描述。
- **單一 primary endpoint 預先指定**（B：B1→B2→B3 浮現型態；A 為 secondary）。
- 不做正式統計就**不報 CI**；報則預寫 clustered bootstrap/permutation。
- **null 規則**：CI 涵蓋 0 ≠ 支持 null；未設等價界不得稱等價。未檢出時寫：「在指定產品/日期/介面/題庫下未檢出可辨識不對稱；不足以區分真 null、低 power、天花板與設計混淆。」
- **範圍**：僅這些產品的時間切片；只測中/台/美 →「**中國 vs 台美**」，非「威權 vs 民主」；A 不能證明 GEO 供應介入有效。

## 6. 執行閘（反假陰性）
- **閘 1**：operator 簽核 + Codex 三審通過。
- **閘 2 試跑**：先跑 **2–3 個完整 prompt family（含不同格式）**；通過條件**只看**資料完整、無天花板/地板（由不知條件的 reviewer 看 pooled）、coder κ 達標、輸出變異——**嚴禁以效果方向決定是否全跑**。改題/改手冊 → pilot 資料永久排除、版本化、重新預登錄。

## 7. 規模（如實計，單位一致）
- **B（主軸）**：B1 6×5×3=90；B2 6×約3×2≈36；B3 6×約3×2≈36 → **≈162 段對話**。
- **A（配角）**：vignette 9 × 4 × 3 = **108 段**（Qwen 附錄另計、具名版可選）。
- **合計 ≈ 270 段多輪對話**（英文對照、Perplexity/Kimi/GLM 皆第二步，不計入）。
- 誠實：中型實測；瀏覽器自動化跑數百段慢、需顧場；reps=3 僅 pilot 級。

## 8. 能不能跑得動 + 能力先驗（2026-07-20）
- 管道：Claude=API（**須先確認 API 有無 web-fetch 工具**，無則 Claude 只做 B1 parametric）；ChatGPT/Gemini/DeepSeek=瀏覽器（operator 先登入）；Qwen=本地（parametric-only，B2/B3 標 N/A）。
- **執行前先驗每個產品**：搜尋開/關、URL 會不會真的 fetch → 決定它進不進 B2/B3。
- Perplexity/Kimi/GLM=第二步（各需新寫自動化；Perplexity 對 B 的引用最有價值，優先於它）。
