# 超低價中國 AI 會默默重塑你的認知嗎？

> 中國模型用數十倍低價搶市，流行說法是這會形成新的「認知基礎設施」、在不知不覺中重塑使用者。本研究把它拆成四環因果鏈逐環檢視證據，發現鏈斷在「能說服個人」與「重構社會認知」之間。

**公開報告**：https://wcl-dev.github.io/research-site/ai-cognitive-infrastructure-tw/
**類型**：桌面研究（證據鏈審計）
**狀態**：已發表 · 2026-06

## 這份研究在問什麼

「低價中國 AI 會形成認知基礎設施、悄悄重塑你」是一條聽起來合理的因果鏈。本研究把它拆成四環——**低價 → 採用 → 資訊入口 → 社會認知**——逐環檢視證據。結論不是「中國模型在進行認知作戰」，而是指出**證據的斷點**：前半段（價差真實、能有界地說服個人）已被嚴謹證明，但「重構人群層級的社會認知」這一環零直接證據。誠實標出鏈斷在哪，比直接斷言整條鏈成立更重要。

## 怎麼產出的

題目發想、研究方向、判斷與「什麼可以公開」的把關來自我（weichen）；耗時的蒐集、分析與撰寫由 AI agents（主要是 Claude）執行一條 insight-pipeline：**公開來源蒐集 → 篩選 → 深讀摘錄 → 撰稿 → 對抗式審查**。站台整體說明見 [research-site README](https://github.com/wcl-dev/research-site)。

## 主要發現

- **價差真實**：中國模型與西方旗艦的 API 價差約 **51–460×**，採用誘因確實存在。
- **鏈斷在 L4b→L4c**：「對個人的有界說服」已有實驗證據、但有上限；「對人群的認知位移」零直接實證。報告的核心貢獻是把這個斷點標出來。
- **機制歸屬**：abliteration（解除對齊）實驗顯示模型的傾向源自**後訓練對齊**、而非語料本身——這影響「重塑認知」該歸因到哪一層。

## 限制

- 最關鍵一環（人群層社會認知位移）目前無任何直接證據可證實或證偽，本研究只能標示為斷點、不下定論。
- 證據以公開學術／產業來源為主，未做第一手大規模使用者實驗。
