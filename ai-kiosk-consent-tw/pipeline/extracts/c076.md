# c076: Guide on Responsible Use of Biometric Data in Security Applications (Singapore PDPC)

**URL**: https://www.pdpc.gov.sg/-/media/files/pdpc/pdf-files/other-guides/guide-to-biometric_17may2022.pdf
**Source type**: 政府監管指引 (新加坡 PDPC) | **Quality**: qs=4
**Deep-read on**: 2026-05-27 (Layer B `curl + pdftotext`)
**Access status**: ok
**Pages/length**: 39+ 頁 (full PDF 已抓取,extract 涵蓋 1-18 頁)

## Directly addresses
- Q5 (國際對照): SG PDPC 對 biometric 在 security applications 的具體合規指引;**明確排除其他商業用途,留下「future guidance for other commercial use cases」聲明** — 對應台灣 A 區商業 inference 灰區同型。
- Q4 (法律屬性對照): SG PDPA 對「consent / 例外」(publicly available data / legitimate interests / employment) 的細分框架,可作為台灣個資法第 6 / 8 條未來函釋的參考。
- Q5 (對台灣 PDPC 籌備處路徑啟示): SG PDPC 採「sectoral guide 漸進」模式,先 security,再「未來」cover commercial — 對台灣 PDPC 籌備處下一步函釋優先順序有實務參考。

## Key passages

### Passage 1 — for Q5 (Scope 明確排除商業 inference)
> 「This Guide is targeted primarily at such security applications that use biometric data. ... This Guide is not intended to address organisations' use of biometric data for commercial purposes other than in security applications. Future guidance will be provided for the separate and distinct considerations that apply in relation to other commercial use cases.」

**Page/section**: Guide pp. 4-5 Introduction (pdftotext layout extract 確認 verbatim)
**Why it matters**: **SG PDPC 明確聲明「商業 inference 用途 (非 security) 留待未來指引」** — 即便是亞洲對個資監管最先進的新加坡,2022/05 時點對「商業 biometric inference」(餐飲 kiosk demographic inference 即屬之) 仍未發布指引。三層解讀:(a) **「security application」與「commercial application」是清楚二分**;(b) **「future guidance」承諾 — 表示監管機構承認此 gap 存在**;(c) **2022/05 至今 (2026/05) 已 4 年,SG PDPC 是否已發布 commercial 指引未在本 extract 確認** — operator 可追蹤。Drafter 在 Q5 對照表可指出:**亞洲 sectoral 漸進立法的「commercial inference 灰區」並非台灣獨有,SG 也在同類待補狀態 — 但 SG 已有明確 sectoral 路徑、台灣 PDPC 籌備處連 security sector 指引都尚未發布**。

### Passage 2 — for Q4 (consent 例外 framework)
> 「Generally, organisations may collect, use or disclose personal data for legitimate purposes recognised by the PDPA, or where an individual gives, or is deemed to have given consent for the notified purposes.」
> 「i. Publicly Available Data ... It allows the collection, use and disclosure of biometric data without consent for security purposes (e.g. monitoring or investigations). ... It is good practice to put up notices disclosing that the area is under surveillance and whether recording also takes place.」
> 「ii. Legitimate Interests ... When the legitimate interests of the organisation or another person in the security use cases outweigh any likely adverse effect on the individual.」

**Page/section**: Guide pp. 15-17 Part III (pdftotext verbatim)
**Why it matters**: **SG PDPA 的 consent 例外體系比台灣個資法更明確**:三類 (deemed consent / publicly available data / legitimate interests) 各有明確 trigger 條件與 best practice 指引。對應台灣個資法 §19 (蒐集適法性) 與 §8 (告知義務),台灣條文較抽象、無具體 sectoral 指引。Drafter 在 Q4 / Q5 可指出:**SG 框架的 transferable lessons** 是 「(a) sectoral 指引明確 trigger、(b) 即使例外 publicly available data,仍要求 'good practice to put up notices' — 即告示要求是 baseline,不因例外免除」 — 此 baseline 邏輯對台灣餐飲 kiosk 「告示零」現狀有直接 framework 對照。

### Passage 3 — for Q7 (儲存與處置 best practice)
> 「Where possible, process biometric samples to biometric templates as soon as practicable, and use only the biometric template for recognition.」
> 「Prevent decrypted biometric templates from persisting in the system by carrying out matching processes for biometric templates in temporary storage (e.g. Virtual memory or Random-Access Memory).」
> 「When biometric data (i.e. biometric samples and templates) are no longer required, ensure that the corresponding entries are permanently deleted from the system.」

**Page/section**: Guide pp. 12-14 Storage / Disposal (pdftotext verbatim)
**Why it matters**: SG PDPC 對 biometric 儲存的具體 best practice (template 而非 raw sample / 加密 / UUID 對映 / temporary storage / 員工離職後永久刪除等) — 是 Drafter 在 Q7 廠商分析「最低 best practice」對照基準。即便 SG guide 是 security sector,storage 與 disposal 的 best practice 跨 sector 通用。Drafter 在 Q7 評價台灣 vendor (WiXtar / 星益欣 / 銓幻元 / CyberLink) 在「resource 處理」面向時可用此 SG baseline 對照 — 例如**台灣 vendor 是否公開「biometric template 不持久化」「離職員工資料永久刪除」這類 storage 邏輯?目前 c032/c041/c044/c045 均未涵蓋。

## Structural content worth knowing
- Guide 涵蓋三個 Part:Part I (what is biometric data + how it's processed) / Part II (how to use responsibly — 5 個 stages: Collection / Processing / Use / Storage / Disposal) / Part III (PDPA obligations 對應)。Drafter 若需完整 framework 可全篇引;若只需 scope statement + consent framework + storage best practice,本 extract 三個 Passage 已涵蓋核心。
- Guide 區分 biometric sample (raw image / video) vs biometric template (encrypted feature vector) — 此 terminology 對 Drafter 在 Q4 法律屬性拆解極重要:**台灣個資法目前無此 sample/template 區分,業者可主張「我們只存 template 不存 sample」豁免,但 SG 把兩者都列為 biometric data**。
- Employment exception (對員工/工讀生 — 雇主可不取得 explicit consent,但要 notification via handbook) 與台灣 c094 勞基法生物特徵出勤紀錄判決 (確認勞基法施行細則明列生物特徵為合法工具) 結構相似 — Drafter 在 Q4 / Q5 對照可指出兩個 framework 在 employment context 收斂。
- **Singapore PDPC 對 demographic inference (年齡/性別/情緒 categorisation,非 identification) 的處理在本 Security Applications guide 未涵蓋** — 是 commercial use 範圍,需待「future guidance」。Drafter 在 Q5 對照表此格 SG 應寫「commercial inference 指引未發 (2022 sectoral 排除)」。

## Caveats / limitations
- Guide 為 2022/05/17 版本,SG PDPC 後續可能已發新 sectoral guide;Drafter 引用 SG 立場時要註明日期。
- 「security applications」與「demographic inference」是 SG 框架下兩個不同範疇 — 不能直接把 security guide 內容套用為 inference 監管,本 extract 著重「scope statement + general framework + storage best practice」三個 cross-sector 可借鏡部分。
- PDF 39+ 頁 extract 僅讀 1-30 頁;Part III 之後 (Annexes、specific scenarios) 未深讀。若 Drafter 需 enrolment / authentication flow 細節可請 operator 追加。
- 「good practice to put up notices」屬 best practice 而非 enforceable mandate,Drafter 引用時要區分 advisory vs mandatory。
