## Structural content worth knowing
- 台中 dataset 涵蓋 2011-2025 共 15 年(半年報),是三個 dataset 中時間 span 最長的;若 row-level 取得後可作 trend analysis ground truth。
- JSON API 主機 newdatacenter.taichung.gov.tw 在 Claude Code 環境 DNS lookup failure — 但這是「Claude Code 環境 network proxy 問題」非「DNS 不存在」,operator 在自家環境應可成功訪問。
- 台中 schema 是抽象 key-value 設計 — 即使有 biometric category 也只會作為「欄位名稱」字串 出現於 row-level,不會在 metadata level 顯示;這個 abstraction layer 反而**讓 Drafter 在 schema 結構性零的 claim 上稍 weaker**(因為理論上 row 可能含 biometric 子類,但未取得 row-level 無法確認)。**Drafter 引用時應 hedge:「c105 + c106 row-level 確認、c107 schema metadata 暗示但未 row-level 驗證」**。
