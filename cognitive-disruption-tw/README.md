# 當網路操弄不再只為政治、也不只為錢

> 似是而非的協同 AI 內容，已無法用「政治攻擊」或「詐騙獲利」單獨解釋——不同動機共用同一套工業化基礎設施，動機只是可替換的內容；首要傷害是對資訊環境本身的無差別「認知破壞」。

**公開報告**：https://wcl-dev.github.io/research-site/cognitive-disruption-tw/
**類型**：桌面研究（命題的證據審計）
**狀態**：已發表 · 2026-06

## 這份研究在問什麼

網路上的協同 AI 內容（AI slop）常被二分為「政治攻擊」或「詐騙獲利」。本研究主張這個二分已失效：**動機是可替換的內容，真正共用的是同一套工業化生產基礎設施**；它對資訊環境造成的首要傷害是無差別的「認知破壞」，再作為後續所有惡意操作的加乘效應。命題鏈為 **(政治∪詐騙) 二分失效 → 共用工業化基礎設施 → 認知破壞（加乘器）→ 需要跨域防治**。本研究誠實標出最弱一環：加乘效應目前缺第一手實證。

## 怎麼產出的

題目發想、研究方向、判斷與「什麼可以公開」的把關來自我（weichen）；耗時的蒐集、分析與撰寫由 AI agents（主要是 Claude）執行一條 insight-pipeline：**公開來源蒐集 → 篩選 → 深讀摘錄 → 撰稿 → 對抗式審查**。證據基礎以廣泛的學術／各國威脅情報／平台揭露為主。站台整體說明見 [research-site README](https://github.com/wcl-dev/research-site)。

## 主要發現

- **二分失效**：以 disinfo-for-hire 產業、GAN 生成帳號跨用途複用、EEAS 的基礎設施矩陣等獨立來源，論證政治/詐騙動機共用同一生產線。
- **認知破壞為首要傷害**：對資訊環境本身的無差別侵蝕，是後續所有操作的加乘效應。
- **誠實標示最弱一環**：「加乘效應」這一命題目前無第一手實證，本研究將其明確標為命題鏈最弱點，而非當成已證結論。
- 兩份台灣一手案例（FB 外連可疑站／YouTube 養生協同網）僅作為實例佐證，**刻意不**用「政治型／詐騙型」二分當分析骨架。

## 限制

- 命題鏈最末段（認知破壞作為加乘效應）缺第一手實證，僅以機制推論支撐。
