# c030: DISINFOX — an open-source threat exchange platform for disinformation and influence operations (Sánchez González et al., Univ. Murcia / UPM, 2025)

**URL**: https://arxiv.org/pdf/2504.01803
**Source type**: preprint (arXiv, SoftwareX 投稿) | **Quality**: qs=4
**Deep-read on**: 2026-06-16
**Access status**: ok (Layer B — pdftotext)
**Pages/length**: SoftwareX 短文(1.9MB PDF)

## Directly addresses
- Q7 [跨域整合框架與交換接口]: DISINFOX 把 DISARM TTP 建模成 STIX2 物件、整合進 OpenCTI 工作流——XD「DISARM→STIX/TAXII 跨組織交換」從框架口號變成可運行平台的具體證據。

## Key passages

### Passage 1 — for Q7 (DISARM→STIX2 的技術骨架,逐字)
> "In particular, DISINFOX models the incidents through DISARM Tactics, Techniques, and Procedures (TTPs), a MITRE ATT&CK-like framework for disinformation, with a custom data model based on the Structured Threat Information eXpression (STIX2) standard."

**Page/section**: Abstract
**Why it matters**: 把 DISARM(disinfo 版 ATT&CK)+ STIX2 標準綁成一個可交換資料模型——這是 XD「共用交換接口」最具體的一句,Drafter 防治段可直引以證「不是『應跨域』口號,而是已有可運行接口」。

### Passage 2 — for Q7 (跨 vendor 統一視圖)
> "This facilitates integration with other vendors, providing a unified view of cybersecurity and disinformation events."

**Page/section**: Abstract
**Why it matters**: 明文把 cybersecurity 與 disinformation 事件整合到統一視圖——XD 跨域(資安×假訊息)整合的設計目標句。

### Passage 3 — for Q7 (已驗證的跨平台交換實例)
> "The intelligence generated from a custom dataset has been tested and utilized by a local instance of OpenCTI, a mature CTI platform, via a custom-built connector, validating the platform with the exchange of more than 100 disinformation incidents."

**Page/section**: Abstract
**Why it matters**: >100 件 disinfo incident 經自建 connector 在成熟 CTI 平台(OpenCTI)間實際交換——XD 接口已被**實證可運行**,不是紙上規格。這是 Q7「成功先例」的硬證據。

## Structural content worth knowing
- 架構:Docker 容器化 + web frontend + backend REST API + public API,接入既有 CTI 工作流。Drafter 可用以說明「資安界既有 CTI 基礎設施可直接承載 disinfo 情資」。
- 與 c031(DISARM↔STIX 映射規格)互補:c031 是映射**標準**,c030 是把標準**實作成平台並驗證交換**的工程證據。

## Caveats / limitations
- FIMI/disinfo 導向 CTI,未含反詐金流追蹤端;XD「反詐×反假訊息」的完整接口仍須由 IMS(c028)+ 識別碼申訴接口等補。
- preprint(SoftwareX 投稿),工程系統論文;>100 incident 為作者自建資料集測試,非大規模生產部署。
