# Jargon map — pipeline term → publication rewrite

Audit trail for the de-jargon pass (insight_v1.md → publication/draft.md).

## Tier-tags → prose hedges
- 【強證據】 → anchor-to-evidence 語氣（「資料顯示」「明文寫」「多個來源都指出」）
- 【爭議中】 → inline 「目前資料不足以完全確認，但…」「需要平衡的一點是…」
- 【推測】 → inline「(本研究的判讀/推論)」「屬於推論」明文標出
- 【專家意見】 → 「X 機構的論述/評估認為…」

## Pipeline workflow refs (removed)
- Finding 1–8 → noun-led narrative 標題（八個小節，不顯示編號）
- Q1–Q8 → 刪除（融入小節主旨）
- cNNN → [n] 編號引用（見 cid-citation-map.md）
- 「依摘要層 sourcing，未經 deep-read 一手驗證」→ 對承重主張保留一手歸屬；次級來源改用較軟措辭，並在文末方法註統一說明「部分次級來源引自摘要」
- accepted 池 → 「採用的資料」
- Confidence / Counter-evidence（段尾標籤）→ 融入散文，反框架直接寫進論述流
- 環 1/2/3 → 「第一環/第二環/第三環」（保留逐環攤開的結構，自然中文）
