# Brief — join-petition-typology-tw

**Project**: Join 提點子的「表達型↔工具型」動機類型學 —— 把一套政治消費主義的類型學方法移植到台灣的制度化數位參與，並以成案結果反向驗證

**Stage**: 0 (Interview — drafted by main session) → 1 (Collect / Code)
**Date**: 2026-06-18

> ⚠️ 本專案性質為**實證編碼研究**，不是純文獻綜述。核心產出是一份**被編碼的提案資料集 + 對「成案 off-diagonal」的解釋**；標準 Collector→Drafter 文獻軌在此是**次要軌**（只負責民主理論框架與互文錨點），主軸是 §「編碼計畫」與 §「實證方法」。

## Intertextual anchor（互文對象）

本專案是對一篇方法論文的**移植式研究（method-transfer study）**：

> O'Brien, E. & Kasianenko, K. (2026).
> **"Boycotting Russia: Expressive and instrumental motivations in political consumerism on social media."**
> *International Political Science Review*. DOI: 10.1177/01925121261442380.

該論文確立的可移植「引擎」：把政治參與文獻裡的**概念軸（表達型 expressive ↔ 工具型 instrumental）**，操作化成**三個從文本可判讀的維度**——(i) 是否指名標的、(ii) 是否試圖賦能他人、(iii) 是否期待具體結果——再套到大量社群數位痕跡上做分類，藉此**回擊「這種行為只是象徵性表態」的成見**，證明它其實沿光譜分布、有結構。

**本專案移植這個引擎，但更換基板並利用一個原文沒有的優勢。** 原文最大的遺憾是「只能推論動機、無法驗證結果」。Join 提點子每一案都附帶**客觀結果 ground truth**（附議數 vs 5000 門檻＝成案與否；機關回應品質可爬），讓類型學可以被**結果反向驗證**——這正是原文 future work 的方向。

## Topic

台灣的「公共政策網路參與平臺（Join）／提點子」常被貶為**許願池**：「一堆罷免某人、把誰送中、開放鋼彈路權的廢提案，附議了政府也只給罐頭回應」。本研究把每一份提案當作一個**行為物件**，沿「表達型↔工具型」光譜替它的**動機簽名**編碼，再對照它的客觀命運（有沒有跨過 5000 門檻成案），問一個被許願池成見遮蔽的問題：**Join 上「會咬」的提案到底長什麼樣，那個結構能不能事前從文本認出來？**

單位是**提案**（artifact），不是提案人——我們編可觀察的文本，不臆測個人內心。這比原文「個人參與者動機」的單位更站得住腳，但須在報告中明寫此單位轉換。

## Core reframe（核心翻轉 + pilot 已修正的方向）

| 面向 | O'Brien & Kasianenko (IPSR 2026) | 本專案 |
|---|---|---|
| 基板 | 推特抵制俄羅斯貼文（個人動機，無結果） | **Join 提點子（制度化提案，有成案 ground truth）** |
| 單位 | 個人參與者的動機 | **提案物件的動機簽名** |
| 類型學任務 | 替「被貶為象徵性的抵制」平反 | 替「被貶為許願池的提案」做動機×結果的交叉測繪 |
| 結果驗證 | 不可得（論文自陳 limitation） | **可得**：成案/門檻（in-dataset）+ 機關回應品質（可爬） |
| 文化基準 | 全球社群媒體 | **台灣 zh-TW 制度化參與** |

**⚠️ Pilot（2026-06-18）已證偽 naive 假設、把題目轉向**（見 §Existing knowledge 細節）：原本預期「工具型提案才會成案」**不成立**——工具型分數與成案只有微弱相關、巨大重疊、兩向決定性反例。**真正的研究標的因此是 off-diagonal**：為什麼高審議品質提案大量石沉、低工具型提案卻能成案。工作命題：**Join 的門檻機制獎勵的是「動員強度」（群體規模／組織後盾／媒體時機），不是「政策merit」；認真的提案被系統性篩掉。** 這接上民主理論「參與量 vs 審議質」的經典張力。

## Key questions

- **Q1** [類型學移植] 如何把原文三維度（指名標的／賦能他人／期待結果）嚴謹地映射到 Join 提案的可編碼欄位（標題＋提議內容＋利益與影響）？編碼簿須能讓不同編碼者（或 LLM 多次）得到一致結果。
- **Q2** [外形 vs 動機 — 本研究的量測核心] Pilot 發現「唯一死刑／鞭刑」類提案有工具型的**外形**（引法條、列條號）卻是表達型的**動機**（懲罰宣洩）。原文的軸講的是**動機**，故必須切出「工具型外形」與「工具型動機」兩層，否則編碼會把民粹重刑案誤判成工具型。如何操作化這個切分？什麼文本特徵能區分「為了解決問題而引法條」與「為了表態而引法條」？
- **Q3** [成案的真實驅動力] 若工具型品質不能解釋成案（pilot 已示），那什麼能？候選控制變項：(a) **受影響群體規模**（軍公教、牙醫師、家長/教師、ACG 創作者…）、(b) **組織後盾**（職業協會／全教總／NGO 領銜 vs 個人提案）、(c) **媒體事件時機**（剴剴虐童案後一票兒虐提案集體過門檻）、(d) 議題類別。如何從提案文本／metadata 近似測量這些？
- **Q4** [off-diagonal 結構] 把提案放進「工具型動機 × 成案」2×2，四格各長什麼樣？特別是兩個 off-diagonal 格——**高工具卻石沉**（選舉流程改革法案、足協全民參與、幼兒園稽查）、**低工具卻成案**（有前科不得任民代、軍公教年終、譴責虐童）——的系統性特徵是什麼？
- **Q5** [機關回應層 ground truth②③] 對成案的提案爬 detail page，機關回應是**實質**還是**罐頭**？回應品質跟提案的工具型動機相關，還是跟群體壓力相關？「許願池→罐頭回應」的因果是否其實是「動員型成案→罐頭，工具型成案→實質」？（這是把 expressive/instrumental 從輸入端延伸到產出端的關鍵測試。）
- **Q6** [民主品質診斷] 綜合上述，Join 作為審議民主基礎設施的健康度如何評估？「許願池」批評的哪部分對、哪部分是誤診？平台設計（5000 門檻、60 天、單一附議＝點讚）如何結構性地偏好動員勝過審議？
- **Q7** [槓桿與設計含意] 若要讓高審議品質提案不被門檻篩掉，有哪些不依賴提案人自帶群眾的介入？（分級門檻、機關主動撈取、審議加權、deliberation-by-design…）須對接台灣機構（國發會、各部會）。對接 [[ocf-open-culture-foundation-tw]] / civic-tech 脈絡。

## 編碼計畫（codebook — 本研究的實證脊椎）

每一份提案編以下變項（v1 由 LLM 規模化編碼，附人工校驗子樣本）：

**A. 工具型外形（form，從文本表層）** — 各 0/1：
- `D1_target`：是否指名具體機關／法條／既有政策（vs「政府/社會」泛指）
- `D2_enable`：是否提供可執行機制／法條草案／統計數據／引用（vs 純斷言）
- `D3_outcome`：利益與影響欄是否寫出可衡量的預期改變（vs 願望/口號）
- → `form_score` = D1+D2+D3 (0–3)

**B. 工具型動機（function，Q2 核心）** — 序數 0/1/2：
- `motive`：底層驅動是 problem-solving（工具）還是 expression/outrage/punishment/identity（表達）。重刑民粹案 = 表達型動機即使 form_score 高。

**C. 結果（outcome）**：
- `endorse`（附議數）、`crossed`（≥5000＝成案，bool）、`response_type`（罐頭/實質/無，Q5 爬蟲補）

**D. 競爭解釋變項（confounds，Q3）**：
- `constituency`（受影響群體規模：個人/小眾/中/大型可動員群體）
- `org_backing`（提議者是個人 / 協會 / NGO / 工會 — 從「提議者」欄＋內文署名近似）
- `media_window`（提案日是否落在相關重大社會事件後 N 週 — 對照新聞時間線）
- `topic`（議題類別）

分析：以 `crossed` / `response_type` 為依變項，檢定 `form_score`、`motive` 在控制 `constituency`/`org_backing`/`media_window` 後是否仍有解釋力 → 量化驗證 off-diagonal 命題。

## 實證方法與資料

- **資料來源**：dataset `58036`「公共政策網路參與平臺-提點子(行政院版本)」（國發會, data.gov.tw, 政府開放授權）。
- **全量取得**：✅ 已抓齊。原始 JSON `https://join.gov.tw/toOpenData/v2/ey/idea?year=2020..2024` → **12,844 件、附議數量 0 筆無法解析（raw JSON 乾淨；CSV 的欄位錯位是正規化 artifact，勿用 CSV 做主分析）**。可再現腳本 `data/fetch_corpus.py`；23MB 原始檔 gitignore，`crossers.json`(162 件) 為 tracked artifact。
- **base rate（全期 2020–2024）**：162 件成案＝**1.26%**；破千 278 件；最高 44,881。**成案率逐年下滑**：2020 **2.00%**(48) → 2021 1.27%(41) → 2022 1.50%(26) → 2023 1.02%(26) → 2024 **0.71%**(21)。→ 「成案率大致走低（惟年度數小、2022 回升、非單調，宜謹慎）」列為一個觀察，off-diagonal 結構是否隨時間改變列入分析。**162 件成案＝off-diagonal 分析的 n。**
- **回應層**：對 `crossed` 提案以 `網址` 逐頁 WebFetch/爬 detail page，取機關回應全文 → 編 `response_type`。
- **規模化編碼**：12,846 件由 LLM 依編碼簿打標；抽 ≥150 件人工雙盲校驗 inter-coder agreement；不一致處回修編碼簿。

## Scope

- **Time window**：提案資料 2020–2024（平台 2015 上線，全量原始 JSON 可回溯更早，v1 先做 2020+）。
- **Geography**：台灣（行政院版本＝中央機關提案）。地方版本（縣市）列為 v2 對照，不進 v1 主結論。
- **Languages**：zh-TW（資料）；en（互文論文＋e-petition/審議民主文獻）。
- **Depth**：methodology（類型學建構與驗證）為主軸，comparative（與原文對讀）為次結構。產出為**可對外發表的研究報告 + 公開的編碼簿與編碼資料集**。

## Inclusion（文獻軌 — 次要，只為框架與互文）

- 互文核心：O'Brien & Kasianenko 2026 IPSR 全文（DOI 上方）。
- 政治消費主義 expressive vs instrumental 類型學文獻（Stolle/Micheletti 等）。
- e-petition / We the People / 連署平台的成案決定因素研究（門檻、動員、組織利益）。
- 審議民主 vs 參與量、slacktivism/clicktivism、數位行動主義文獻。
- Join 平台本身的研究、成效報告、批評（國發會、學界、g0v、媒體）。

## Exclusion

- 把美國 We the People 的數字／結論**直接套用**到 Join 而不重新驗證。
- 參與式預算、公投連署（**不同機制**——不同法律門檻與單位，只作對照不混入主資料）。
- 一般「數位轉型／開放政府很好」的政策宣導文、無機制論證的評論。
- 純技術的平台介面 UX 討論（除非觸及門檻機制的結構偏好）。
- 把單一爆紅提案的軼事當成全平台結論（須回到 12,846 件母體）。

## Existing knowledge（operator priors — pilot 已產出證據，Drafter 視為起始事實但仍須全量複核）

1. **類型學編得出來**：D1/D2/D3 從提案文本可判讀（pilot 在 48 件上確認）。
2. **naive 假設「工具型→成案」已證偽**：成案/近門檻/長尾三組 form_score 平均僅 2.7/2.3/1.8，重疊巨大。決定性反例——低工具卻成案：「有前科不得任民代」(5,504)、「軍公教年終2個月」(5,681)、「童年無價譴責虐童」(5,254)；高工具卻石沉：「台灣選舉流程改革法案」(完整法條草案, 3,732)、「足協全民參與」(引國民體育法, 900)、「幼兒園稽查改革」(引監察院數據, 874)。
3. **成案真正驅動力**＝群體動員規模／組織後盾／媒體事件時機（剴剴虐童案後一票兒虐提案集體過門檻為最清楚證據），非審議品質。
4. **量測陷阱**：重刑民粹案（唯一死刑/鞭刑）有工具型外形、表達型動機 → 必須切 form vs motive（Q2），否則高估工具型佔比。
5. **單位轉換**：本研究編「提案物件的動機簽名」，非「提案人私密動機」——報告須明寫，避免過度心理化推論。
6. 全量已抓：12,844 件、**全期成案率 1.26%（162 件）、逐年下滑 2.00%→0.71%**；raw JSON 乾淨（CSV 欄位錯位是正規化 artifact）。見 §實證方法與資料、`data/fetch_corpus.py`、[[join-typology-pilot]] 記憶。

## Success criteria

**好的最終洞察 —— 須全部成立**：

1. 類型學移植**嚴謹**：編碼簿可複現、inter-coder agreement 有報告、form vs motive 切分（Q2）被當核心量測問題處理。
2. off-diagonal 命題被**量化驗證**：在控制群體規模/組織後盾/媒體時機後，檢定工具型品質對成案的（無）解釋力——而非只給軼事。
3. 機關回應層（Q5）真的去爬，把 expressive/instrumental 延伸到產出端，檢驗「動員型成案→罐頭 vs 工具型成案→實質」。
4. 對「許願池」成見給出**有證據的細緻裁決**：哪部分對、哪部分是誤診。
5. 全程區分三層：(a) pilot 已示的、(b) 全量分析確立的、(c) 受資料限制仍無法定論的。
6. 單位轉換（提案物件 vs 個人動機）誠實標示，不過度心理化。

**失敗條件**：

- 退回 naive 框架「工具型提案才會成功」（pilot 已證偽）。
- 把工具型**外形**當**動機**，高估審議品質佔比（Q2 陷阱）。
- 用攤平 CSV（只 2024 + 欄位錯位）當全量分析基礎。
- 軼事驅動，沒回到 12,846 件母體與控制變項。
- 把美國 We the People 結論直接當台灣結論。

## Scoping decisions（已拍板 2026-06-18）

- **D-1 編碼規模**：✅ **hybrid case-control 1,076 件**（operator 於 collect 前修訂，取代原「全量」）：全部 162 成案 + 214 高附議對照 + 700 分層隨機長尾。理由：off-diagonal 結果分析用 case-control 即足、成本 ~6%，隨機那批可 IPW 加權回推母體（母體＝12,844 件，非 12,846）。**注意**：因控制組選取依附議量，Stage-1 須報 IPW 加權母體估計（見 review.md / offdiagonal.md 穩健性附錄）。
- **D-2 回應層深度**：✅ **v1 就爬全部歷年成案 detail page 機關回應**，編 `response_type`（罐頭/實質/無）。Q5「動員型成案→罐頭 vs 工具型成案→實質」是承重發現。
- **D-3 媒體時機變項**：✅ **v1 就建重大社會事件時間線、納入 `media_window`**。三個 confound（群體規模／組織後盾／媒體時機）v1 全收。

→ v1 範圍 = 全量輸入端編碼 + 成案回應層 + 三個 confound 全納。執行軌：①全量原始 JSON 取得 → ②codebook.md → ③LLM 規模化編碼 + 人工校驗 → ④成案回應層爬蟲 → ⑤社會事件時間線 → ⑥off-diagonal 分析 → ⑦文獻軌 collect → ⑧draft。
