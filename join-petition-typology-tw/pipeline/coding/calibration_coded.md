## 校準結論

**1. 編碼簿可用**：20 件全可依簿打標，D1/D2/D3 機械、`form` 穩定。

**2. off-diagonal 在校準尺度就清楚成立**：
- 高 form(3)/工具動機(2) 卻**死**：選舉法案(3732)、足協(900)、幼兒園稽查(874)、午餐升級(11)。
- 低 form/表達動機卻**成案**：軍公教(form2,5681)、有前科(form0,5504)、童年無價(form1,5254)。
- **`form`/`motive` 都無法預測成案；`constituency`+動員才能。**

**3. 兩個最有力的證據**（值得在報告 feature）：
- **波波牙醫戰爭**：#03 支持 + #04 反對，**同議題對立兩案雙雙破 5000**。審議品質不可能同時站兩邊 → 驅動成案的是**組織化職業動員**，近乎實驗級證據。
- **午餐升級計畫**：跨三部會、結構完整、form=3 的提案只拿 **11 附議**。審議品質 ≠ 牽引力，最刺眼的反例。

**4. 校準暴露、需補進編碼簿的規則**（calibration 的真正產出）：
- **(R1) 外國法引用 ≠ D2**：引新加坡鞭刑、法國檢舉制度當修辭錨點，未落成台灣可執行機制者，D2=0（否則高估 #02 #20 的 form）。
- **(R2) 新增 `ai_essay_suspect` 旗標**：#15 #16 #19 讀來像 LLM 代寫長文——D1/D2/D3 表面全高、卻零群體零牽引。AI 文體會**膨脹 form_score** 卻是空心的，是真實量測威脅。需獨立旗標，且更加證明不能只靠 form。
- **(R3) `constituency` 拆「潛在規模」vs「實際動員」**：幼兒園稽查(#12)有家長群體+媒體時機仍死 → 潛在群體大 ≠ 被動員。這正是 `org_backing`（有沒有協會/工會把人催出來）承重之處。
- **(R4) `motive` 邊界確認可操作**：法律外形包民怨（#20 交通檢舉）判 motive=1；民粹重刑無配套（#01 #02）判 0；程序性問題解決（#10 #15 #19）判 2。§B 規則夠用。

→ 編碼簿 patch 後（R1–R3），1,076 件主跑可啟動。
