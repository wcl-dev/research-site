# Codebook — join-petition-typology-tw

**版本** v1.1（calibration-patched R1–R3，見 [calibration_coded.md](calibration_coded.md)）· 2026-06-18 · 對應 [brief.md](../brief.md) Q1–Q5
**編碼單位**：一份提案（提點子 idea，artifact）。編可觀察文本，**不臆測提案人內心**。
**輸入欄位**：`標題` + `提議內容` + `利益與影響`（必要時 `提議者`）。
**資料**：`data/idea_2020_2024.json`（12,844 件，raw JSON）。

> 設計原則：每個變項都要能讓**不同編碼者 / LLM 多次**得到一致結果。凡需主觀判斷處，附「決策規則」與雙向真實案例（取自 pilot 48 件 + 162 件成案）。inter-coder agreement 目標 κ ≥ 0.6；未達則回修本簿。

---

## A. 工具型外形（form）— 文本表層，各 0/1

判讀「提案在**形式上**有多像一份要解決問題的提案」。只看有沒有，不看真不真誠（真誠度交給 §B `motive`）。

### `D1_target` — 是否指名具體標的
- **1**：點名具體**機關／法條條號／既有政策或計畫名**。例：「衛福部『優化偏鄉醫療精進計畫第二期』」「刑法271、286條」「道交條例第2條」「兒少法83-1」。
- **0**：只泛指「政府／社會／國家」，或標的模糊。例：「政府不要再爛」「社會應重視」。
- 決策規則：出現**至少一個可被行政體系定位的具體對象**即 1。

### `D2_enable` — 是否賦能他人 / 提供可執行材料
- **1**：提供**機制設計／法條草案文字／統計數據／引用來源／具體步驟**，讓主張可被接手執行或檢證。例：附監察院稽查覆蓋率數字；給出第51-1條增修草案全文；列 EU FEDIAF/US AAFCO 標準。
- **0**：純斷言、訴諸情緒、或只表達立場而無可操作內容。
- 決策規則：有**任一**可獨立查證或可直接被採用的材料即 1。「我覺得應該…」不算；「依87台教字第26698號函，建議改為380元」算。
- **(R1, 校準補) 外國法引用 ≠ D2**：引新加坡鞭刑、法國檢舉制度等當修辭錨點、**未落成台灣可執行機制**者，D2=0。除非提案把外國制度具體轉譯成台灣的修法/施行步驟。

### `D3_outcome` — 是否寫出可衡量的預期結果
- **1**：`利益與影響` 欄寫出**具體、有界、可衡量**的預期改變。例：「統一補助為每月13000元」「教師人身安全＋管教權獲保障，校安事件數下降」。
- **0**：願望或口號。例：「保障國家未來命脈」「讓社會更好」。
- 決策規則：問「這個結果達成與否，事後能不能判斷？」能 → 1。

**`form_score` = D1_target + D2_enable + D3_outcome（0–3）**

### `ai_essay_suspect` — 疑似 LLM 代寫長文（0/1）〔R2, 校準新增〕
- **1**：通篇結構化小標、面面俱到、語氣均勻無個人聲音、利益分「健康/教育/經濟層面」三段式——典型 LLM 代寫徵候（校準 #15 午餐升級、#16 新竹合併、#19 招標監督）。
- 為何要：AI 文體會把 D1/D2/D3 **表面全撐到高**、`form_score` 膨脹，卻零群體零牽引（午餐升級 form=3 只 11 附議）。這是真實量測威脅，須獨立旗標，分析時檢查 form-high 是否被 AI 文灌水。

## B. 工具型動機（motive）— 底層驅動，序數 0/1/2 〔Q2 量測核心〕

**這是本研究最承重、也最易錯的判斷。** Pilot 顯示：有些提案 `form_score` 高（引法條、列條號），底層卻是**表達型動機**（懲罰宣洩／道德表態／身分認同），原文的軸講的是**動機**，故須獨立編。

- **2 工具型動機**：核心驅力是**解決一個具體問題**；引用的法條/數據是**為了讓解法可行**。例：教學支援鐘點費（為補薪資落差，梳理函釋沿革）、藝文票券定型化契約（為修退換票機制）。
- **1 混合 / 難判**：問題解決與表態各半，或文本不足以判斷。
- **0 表達型動機**：核心驅力是**表態／宣洩／懲罰／身分動員**；即使引了法條，法條是**情緒的修辭載體**。例：「虐童致死唯一死刑」（引刑法271/286 但驅動是懲罰宣洩）、「兒少性侵鞭刑」（引新加坡法）、「有前科不得任民代」（純道德標準主張）。

**`motive` 與 `form_score` 的關鍵組合**（off-diagonal 的種子）：
| form_score | motive | 標籤 | 真實例 |
|---|---|---|---|
| 高(2–3) | 2 | 真工具型 | 偏鄉牙醫、票券契約、教學鐘點費 |
| 高(2–3) | 0 | **工具外形/表達動機**（民粹重刑） | 虐童唯一死刑、性侵鞭刑 |
| 低(0–1) | 0 | 純表達 | 「政府不要再爛」式、凜沁夜羽系列 |
| 低(0–1) | 2 | 工具動機/寫得少 | 簡短但對準具體問題的提案 |

決策規則（區分「為解決而引法條」vs「為表態而引法條」）：看**訴求的刑度/罰則是否與問題規模成比例**、**是否討論配套與副作用**、**語氣是程序性還是道德義憤**。一律死刑/最重本刑 + 無配套 + 義憤語氣 → motive 0。

## C. 競爭解釋變項（confounds）〔Q3〕

成案的真正驅動力候選，作為控制變項。

### `constituency` — 受影響群體**潛在**規模（序數 0–3）
- 3 大型可動員群體（軍公教~100萬、全國家長/教師、寵物飼主、ACG 創作者社群）
- 2 中型職業/利益群體（特定職業如牙醫師、特定產業）
- 1 小眾/地域（某運動項目、某縣市、某罕見處境）
- 0 個人處境/無明顯群體
- **(R3, 校準補) 這編的是「潛在規模」，不是「是否真被動員」**。潛在群體大 ≠ 會成案：幼兒園稽查(#12)有家長群體+媒體時機仍死。實際動員力靠 `org_backing`（有沒有協會/工會把人催出來）+ `media_window` 承擔。分析時 constituency × org_backing 一起看。

### `org_backing` — 組織後盾（類別）
- `none` 個人提案
- `assoc` 職業協會/產業協會領銜（如台灣運動產業協會、全教總）
- `ngo` 倡議型 NGO/基金會
- `gov_adjacent` 半官方/受影響機構內部
- 判讀來源：`提議者` 欄 + 內文署名/自我介紹（「我是…理事長」「全教總認為」）。

### `media_window` — 媒體事件時機（0/1 + 事件標籤）
- **1**：`提送日期` 落在一條**重大相關社會事件**後 N 週內（預設 N=8）。例：2024 剴剴虐童案 → 其後兒虐/兒少安全提案叢發。
- **0**：無對應事件。
- 需另建 `data/events_timeline.yaml`（事件名／日期／關鍵詞／議題域），編碼時比對提案議題 + 日期。

### `topic` — 議題類別（受控詞表）
司法/刑罰、教育、勞動/軍公教、醫療/長照、兒少保護、交通、動物、租稅/補助、國會/選制、文化/創作、移民、其他。

## D. 結果變項（outcome）〔Q4–Q5〕

- `endorse`：附議數量（int，raw JSON）。
- `crossed`：`endorse >= 5000`（bool）。全期 162 件 = 1.26%。
- `response_type`〔Q5，爬 `網址` detail page〕：
  - `substantive` 機關具體承諾/修法/政策調整
  - `boilerplate` 罐頭（重申現狀、不予處理、制式說明）
  - `none` 查無回應
  - `pending` 仍在處理期
- `response_quote`：機關回應關鍵句（供 Drafter 引用，須回 detail page 原文，不可由 summary 合成 — 見 [[feedback-webfetch-summary-fabrication]]）。

## E. 編碼程序

1. **校準集**：先抽 ~20 件邊界案例（含每個 off-diagonal 格），由 LLM + 人工各編一輪，比對 → 修本簿至穩定。
2. **規模化**：對母體（全量或 case-control 樣本，依執行決定）以本簿 LLM 編碼，輸出 `coding/coded.jsonl`（一列一提案，含全部變項 + `coder`/`model`/`confidence`）。
3. **人工校驗**：隨機抽 ≥150 件雙盲人工編，算 κ；`motive` 與 `media_window` 因主觀，單列報告 agreement。
4. **回應層**：對 162 件成案爬 detail page 編 `response_type` + `response_quote`。
5. **分析**：見 `analysis/offdiagonal.md` — 以 `crossed`/`response_type` 為依變項，檢定 `form_score`、`motive` 在控制 `constituency`/`org_backing`/`media_window`/`topic` 後的（無）解釋力。

## F. 已知難判案例（boundary rulings — 持續追加）
- 重刑民粹案：form 可高、**motive 一律先判 0**，除非有配套/比例討論。
- 自利型動員（軍公教加薪）：form 常低（D2 弱）、motive 視是否就事論事（加薪訴求＝表態性高 → 多為 0–1）、constituency 高。此格是「低工具×成案」主力。
- 高品質卻小眾（足協全民參與、幼兒園稽查、選舉流程改革法案）：form 高、motive 2、constituency 低/中、crossed 0。此格是「高工具×石沉」主力，**研究的解釋重心**。
