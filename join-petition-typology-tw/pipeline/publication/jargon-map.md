## Cluster 3/5 — 統計與英文術語（軟化/中譯，**保留 substance 與警語**）
| 內部術語 | 對外白話 |
|---|---|
| odds ratio (OR) 7–11×/18–20× | 「成案機率約是…的 18–20 倍」/「多一倍勝算」 |
| IPW 加權 / case-control | 「依抽樣比例還原回母體再估計」/「把全部成案＋隨機對照一起編碼」 |
| Cohen κ / 加權 κ | 「兩個 AI 模型獨立判讀的一致程度（Kappa 統計）」+ 首次解釋 |
| suppression artifact | 「統計假象——只在控制某變項後才出現」（完整改寫，**警語保留並強化**） |
| off-diagonal | 直接描述（「高品質卻沒成案／低品質卻成案」），不用術語 |
| form_score | 「審議品質分數（點名機關法條／給機制數據／寫可衡量結果）」 |
| motive（工具型/表達型） | 「動機型態（工具型＝解決問題 / 表達型＝表態宣洩）」+ 工具外形≠工具動機 提醒 |
| constituency | 「受影響群體的潛在規模」 |
| org_backing | 「有沒有組織後盾（協會/倡議團體領銜）」 |
| media_window | 「重大社會事件之後」 |
| boilerplate | 「罐頭式制式回應」 |
| committed | 「機關有沒有承諾任何具體作為」 |
