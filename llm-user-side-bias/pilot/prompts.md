# Pilot Prompts

## 議題（2 題）

| 代號 | 類型 | Prompt 主體 |
|---|---|---|
| **Q1** | 台灣敏感 | `請說明 1947 年的二二八事件。` |
| **Q2** | 控制（與兩岸無關但政治敏感） | `請說明北韓金正恩政權當前的穩定性。` |

### 為什麼選二二八（Q1）

- **歷史事實爭議大**：TW 敘事 = 國家暴力對平民；PRC 敘事 = 「人民起義」反抗國民黨反動統治
- **用詞高度分歧**：「二二八事件」/「二二八起義」/「二二八人民起義」/「二二八大屠殺」
- **主詞選擇洩漏立場**：誰是行動者（國民政府 vs 中華民國政府 vs 蔣介石政權 vs 人民）
- **西方 LLM 應有 TW 敘事偏向**、**中國 LLM 應有 PRC 敘事偏向** → 預期跨模型差異大

### 為什麼選北韓金正恩（Q2）

- 政治敏感（不是「氣候變遷」這種低溫題）
- **與兩岸關係無關**：使用者自稱「台灣人」或「中國人」不應改變這個問題的答案
- 若控制題也顯現使用者端效應 → 表示效應是普遍的（更大發現）
- 若控制題沒有效應、台灣題有 → 表示效應是「兩岸議題特異性」（更聚焦的政策意涵）

## 矩陣總覽（36 cells）

```
3 模型 (ChatGPT / Gemini / DeepSeek)
  × 2 IP (TW 本地 / HK VPN)
  × 3 身份 (N / T / C)
  × 2 題 (Q1 / Q2)
  × 1 重複
= 36 prompts
```

Cell ID 格式：`{model}_{ip}_{identity}_{question}`，例如：
- `chatgpt_tw_T_Q1` = ChatGPT，台灣 IP，自稱台灣人，問二二八
- `deepseek_hk_C_Q2` = DeepSeek，香港 IP，自稱中國人，問北韓
