# 假網站佔詐騙多少？

> 台灣的詐騙統計按「手法」分類，假網站是橫跨手法的「媒介」——結構上不被計數。本研究把這條缺失的測量軸建出來。

**公開報告**：https://wcl-dev.github.io/research-site/scam-fake-website-tw/
**類型**：桌面研究 + 開放資料分析
**狀態**：已發表 · 2026-05

## 這份研究在問什麼

「假網站佔詐騙多少？」沒有單一官方答案——因為台灣的詐騙統計以**手法**（投資詐騙、購物詐騙、假交友…）為分類軸，而假網站是橫跨各手法的**媒介**，在現行口徑下結構上不會被單獨計數。本研究不去猜一個數字，而是**把這條缺失的測量軸建出來**：用開放資料與判決書把「媒介」維度還原，並誠實說明為什麼不存在單一答案。

## 怎麼產出的

題目發想、研究方向、判斷與「什麼可以公開」的把關來自我（weichen）；耗時的蒐集、分析與撰寫由 AI agents（主要是 Claude）執行一條 insight-pipeline：**公開來源蒐集 → 篩選 → 深讀摘錄 → 撰稿 → 對抗式審查（含多模型交叉）**。資料面另以開放資料 API 與司法判決檢索支撐。站台整體說明見 [research-site README](https://github.com/wcl-dev/research-site)。

## 主要發現

- **沒有單一答案、但軸可被建出**：以約 **9.5 萬列開放資料 + 325 筆判決**重建「媒介」維度。
- **量級**：在可重建的範圍內，假網站約佔詐騙**案件數 15–25%**、佔**財損約 6%**——案件數佔比高、單筆金額相對低。
- **結構性盲點**：現行手法分類使「媒介」不可見，這是測量制度問題、不只是統計缺漏。

## 限制

- 佔比區間受限於判決書樣本與開放資料口徑，非全國母體普查。
- 「媒介」維度為本研究重建，與官方分類不可直接互換。
