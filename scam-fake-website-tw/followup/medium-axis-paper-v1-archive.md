# 台灣以假冒網域／假網站為手段的詐騙：一個媒介軸的盛行率估計

> **scam-fake-website-tw 研究弧 · 最終整合論文（P5＋P6）· 2026-05-23**
> 整合 Phase 1（綜述）與 Phase 2（一手實證 P0–P4）。本文 §3 即 P5 媒介軸估計、§5 即 P5 給 165/NPA 的欄位建議；P5、P6 合併為這一份，避免重複。

## 摘要

本研究問「台灣以假冒網域／假網站為手段的詐騙佔多少比例」，發現這個問題**按原樣無法回答** —— 因為台灣的詐騙統計按「手法」分類（假投資、網購、假交友…），而「假網站」是一條橫跨各手法的「媒介」，官方統計**沒有這一軸**。本研究不停在這個死路，而是用一手資料把缺失的軸**自己建出來**：逐列分類約 9.5 萬列政府開放資料的詐騙 artifact 清單（供給端），並編碼約 116 份一審刑事詐欺判決、約 325 筆被害人（需求端），產出**台灣第一張「手法 × 媒介」交叉表**。

結論：**獨立假網站是約 15–25% 詐欺案件的核心媒介（案件加權），但只佔約 6% 的詐欺財損**；且高度隨手法變化 —— 從 0%（假檢警、假客服）到約 48%（假冒物流）。若把「假冒/詐騙集團自建的 APP」也算進廣義「假數位介面」，則達 35–60%。**真正的交付物不是一個數字，而是一張表**，以及一個具體建議：165／警政署應在詐騙案件登錄端新增「媒介」欄位，讓這條軸能被原生、全國、持續地測量。

## 1. 問題與背景

### 1.1 研究問題

「台灣以假冒網域、假網站作為手段的詐騙佔比多少？」這是一個看似簡單、政策上也常被問起的量化問題。Phase 1 的綜述（多輪搜尋政府、學界、業界量化資料）得到一個關鍵發現：**這個問題沒有單一官方答案，而且「沒有答案」本身有結構性原因。**

### 1.2 為何沒有官方數字 —— 分類軸的錯位

台灣的官方詐騙統計（165 打詐儀表板、警政署統計通報、各縣市警局）**一律按「詐騙手法／類型」分類**：假投資、網路購物、解除分期付款、假交友、假冒機構…。而「假網站」不是一種手法 —— 它是一種**媒介／工具**，橫跨多種手法（假投資可以用假網站、也可以用 LINE 群組；網購詐騙可以用假網站、也可以用真平台假賣家）。

官方統計裡**沒有「媒介軸」**。因此「假網站佔比」結構上不被計數 —— 這不是統計疏漏，是分類體系的設計。任何「假網站佔比」的數字，都必然是「多分母、多估計法」的問題。

### 1.3 Phase 1 能講到的天花板

Phase 1 綜述能給的，是各種**分母不一**的代理數字：業界（Whoscall 2025）指偵測到的「惡意連結」中網路釣魚網站約佔 **30.52%**；數位部下架管道中「詐騙網站」僅佔 **1.33%**（該管道偏社群假廣告）；2024 年詐欺佔全般刑案 **32.14%**；TWNIC RPZ 2025 年停止解析 **79,039 個網域**。這些數字分母彼此不同、不可互換或合成。

Phase 1 的結論因此停在「**說清楚為何沒有數字 + 給多分母區間**」。一個對它的對等價值評估（多模型）判定這份綜述為「中等價值」—— 因為核心數字都是別人的。要把價值推到「原創」，唯一路徑是**自己產出一個原本不存在的數字**。這就是 Phase 2。

## 2. 方法

### 2.1 核心方法論主張：bottom-up

官方統計是 **top-down**（先有手法分類框、案件往裡填，永遠切不出媒介）。本研究是 **bottom-up**：政府其實已公開多份「**逐筆詐騙 artifact 清單**」（網址、網站、網域），每一筆都是具體物件、**可以逐列依媒介分類**；法院判決則逐案、含被害人與財損地描述「被害人如何被騙」。把這些**由下而上編碼**，就能重建一條 top-down 統計給不出的媒介軸。

### 2.2 概念與編碼框架（codebook v1.3）

- **核心媒介 D1**（被害人實際發生損失的所在）：M1 獨立假網站／M2 真平台假帳號·假賣場／M3 假冒或詐騙集團自建 APP／M4 通訊軟體（無網站，如純 LINE 群組）／M5 純語音電話／M6 實體面對面／M0 無法判定（含判決未述）。
- **觸及 vs 核心**：被害人「最初怎麼被接觸到」（簡訊、社群廣告）是觸及層，與「損失發生在哪」（核心媒介）嚴格分開。
- **手法 D4**、**冒名子型**（A 冒名型／B 自建型）、**財損 D6**。
- codebook 經三輪信度檢驗修訂後凍結於 v1.3。

### 2.3 三條腿

- **Leg A 供給端**：逐列分類 3 個政府開放資料集 —— 165027（數位部聲請停止解析網域）、160055（165 假投資博弈網站）、176455（165 遭停止解析涉詐網站），合計約 95,300 列。
- **Leg B 需求端**：分層抽樣編碼一審刑事詐欺判決，逐被害人編 D1/D4/D6。
- **Leg C 三角驗證**：對照業界偵測資料（Whoscall 等）。

### 2.4 分類引擎與信度

採三層 hybrid：規則層（描述欄解析、品牌清單比對）→ LLM 層（判讀）→ 人工/雙模型裁決。**信度以兩個獨立編碼者（Claude、Codex）+ Cohen's κ 檢驗**：
- Leg A（160055 站名分類）：D3 二分「冒名 vs 非冒名」κ = **0.776 PASS**（三分類因「自建 vs 無法判定」邊界不可靠而收斂為二分）。
- Leg B（判決編碼）：D1 核心媒介 κ = **0.778 PASS**、D4 手法 κ = 0.722 PASS。
- 並建置一套 typosquat 偵測演算法（網域字串比對品牌語料庫），驗證精確度 100%、召回率約 39%（高精確度的下界偵測器）。

### 2.5 方法限制（前置聲明）

- 供給端是「被通報／被攔阻」的 artifact，非受害母體；需求端是「已起訴」案件。
- 判決約 24–32% 對核心媒介「未具體記載」（M0）—— 是判決書記載粒度限制，使 M1 成為下界。
- 起訴偏誤：境外一頁式假購物站難起訴，需求端對該類 M1 系統性低估。

## 3. 結果

### 3.1 供給端（Leg A）—— 假網站基礎設施的規模與組成

| 資料集 | 去重後規模 | 冒名型（A）佔比 | 要點 |
|---|---|---|---|
| 165027 數位部停止解析網域 | 1,466 網域 | **72%**（28% 為定義灰區）| 幾乎全是冒名電商（樂信、蝦皮、樂天…），通報排名受電商業者通報活躍度影響 |
| 160055 165 假投資博弈站 | 8,574 站名 | 站數 **15–20%**／件數 ~34% | **多數假投資站用自創品牌**（0xBoost 之類），冒名是少數 |
| 176455 165 涉詐網域 | 48,575 列 → **11,683 母網域** | typosquat 確證 **≥9%** | **域名農場灌水 4.2×**：12 個農場母網域灌出 74% 的列；冒名以 7-11 賣貨便為最大宗 |

供給端三大發現：(1) **冒名比例隨手法相反** —— 假購物站幾乎全冒名、假投資站多自創品牌；(2) **「假網站數量」嚴重依賴計數單位** —— 176455 的 4.8 萬列去重後只剩 1.17 萬母網域；(3) 三個資料集是三條不同通報管道，各自只看見冒名生態的一塊（電商／金融／物流超商）。

### 3.2 需求端（Leg B）—— 旗艦：手法 × 核心媒介交叉表

約 116 份一審判決、325 筆被害人。**這張表台灣目前不存在：**

| 手法 | M1 獨立假網站 | M2 真平台假帳號 | M3 假冒/自建APP | M4 通訊軟體 | M5 純電話 | M0 判決未述 | n |
|---|---|---|---|---|---|---|---|
| 假投資 | 8 | 0 | **38** | 0 | 0 | 24 | 70 |
| 網購 | 4 | **61** | 0 | 1 | 0 | 5 | 71 |
| 假冒物流 | **27** | 0 | 0 | 0 | 0 | 29 | 56 |
| 解除分期假客服 | 0 | 0 | 0 | 0 | **22** | 0 | 22 |
| 假交友 | 2 | 0 | 0 | **15** | 0 | 17 | 34 |
| 假冒機構（假檢警）| 0 | 0 | 0 | 0 | **57** | 0 | 57 |

**核心發現：媒介幾乎完全由手法決定。** 每種手法有它自己、單一主導的媒介：假檢警與假客服 100% 純電話；網購 86% 是真平台假賣家；假交友靠通訊軟體；假投資靠自建 APP；唯假冒物流（賣貨便驗證詐騙）以獨立假網站為主。獨立假網站佔比從 **0% 到 48%**，完全看手法。

### 3.3 三角整合與盛行率加權估計

把旗艦表用手法盛行率加權（**以嘉義市 52459 為範例** —— 唯一可得的案件級手法開放資料集；非宣稱全台代表，權威估計須以 165 全國分布重做）：

| 口徑 | 估計 |
|---|---|
| 獨立假網站（M1）佔詐欺**案件** | **15–25%**（案件加權、中位 ~20%；硬下界 14.5%）|
| 獨立假網站佔詐欺**財損** | **僅 ~6%** |
| 含假冒/自建 APP（M1+M3）佔案件 | **35–60%** |
| 真平台假帳號（M2，明確非假網站）| ~18–20% 案件 |
| 純電話（M5）| ~6% 案件（但隨手法，假檢警類達 100%）|

**三條腿收斂**：需求端案件加權 M1 ≈ 15–26%；業界 Leg C（Whoscall）惡意連結中釣魚網站 30.52%（分母不同但同量級、方向一致）；供給端假網站基礎設施數量龐大但 moda 下架中「詐騙網站」僅 1.33%（管道偏社群廣告）。三者不矛盾，各自照亮不同切面，一致指向同一結論。

## 4. 討論

### 4.1 回答原始問題

**假網站是台灣詐騙的重要基礎設施之一、約涉及五分之一的案件 —— 但它不是主導媒介。** 電話、真平台假帳號、自建 APP 各自佔相當或更大的份額。而且以**金額**計，假網站影響甚小（~6%）—— 它是低額通道（網購、物流類小額詐騙），大錢在假投資（自建 APP）與假檢警（電話）。

### 4.2 供給 ≠ 需求

供給端有上萬個假冒電商網域被通報下架（165027），但需求端的網購被害人**86% 其實是在真平台（蝦皮、FB 社團）遇到假賣家**，不是獨立假網站。假網站的「供給」是真的、會被攔阻，但多數網購被害人的實際遭遇不是它。這個落差是「假網站佔比」最容易被誤讀之處。

### 4.3 「假網站」框架漏掉的兩條通道

(1) **假冒/自建 APP（M3）** —— 假投資詐騙的主力其實是詐騙集團自建的投資 APP，且是財損最大宗（佔判決財損 35.8%）。只問「假網站」會完全漏掉這條。
(2) **域名農場與計數單位** —— 176455 的「4.8 萬個涉詐網站」去重後僅 1.17 萬母網域。任何「假網站 N 個」的引用都必須先問：列、hostname、還是母網域？

### 4.4 真正的政策意涵

這份研究最有價值的，不是「假網站佔 X%」這個數字本身（它是區間、依分母、依手法），而是：**台灣現行統計切不出「媒介軸」，本研究是第一次把它切出來。** 問題的本質是統計基礎設施的缺口。

---

## 5. 政策建議 —— 給 165／警政署

1. **在詐騙案件登錄端新增「核心媒介」欄位**，值域建議：獨立假網站／真平台假帳號·假賣場／假冒或自建 APP／通訊軟體（無網站）／純語音電話／實體面對面／其他。如此「手法 × 媒介」交叉表即可被**原生、全國、逐月**產出，不必再靠本研究這種逐案編碼。
2. **「假網站數量」的公開統計一律標明計數單位**（母網域／hostname／列），並以**母網域**為主口徑 —— 因域名農場會把數字灌大數倍。
3. **區分供給端與需求端指標**：攔阻量（停止解析、下架）是供給端產出，不可當「受害佔比」引用。
4. 若要一個權威的全台「假網站佔比」，須以 165 全國手法分布對本研究的手法×媒介表重新加權。

---

## 6. 結論

本研究產出**台灣第一份詐騙「媒介軸」的盛行率估計**與第一張「手法×媒介交叉表」。對原始問題「假網站詐騙佔比多少」，誠實的答案是一組有結構、有來源、有區間的估計：**獨立假網站佔詐欺案件約 15–25%、財損約 6%，並隨手法在 0–48% 間劇烈變化。**

從 Phase 1 到 Phase 2，這份研究走過的路是：先誠實承認「沒有數字」，再用一手資料把「沒有數字」變成「一張表」。最終的交付物 —— 一張表，加上一個讓這條軸能被持續測量的制度建議 —— 才是真正源自我們自己一手資料的原創貢獻。

## 限制與誠實聲明

- **加權以嘉義為例**，非全台代表；權威估計須以 165 全國手法分布重做加權。
- **M0（判決未述媒介）24–32%** 是判決記載限制；M1 取下界、上界以 medium-known 推估。
- **起訴偏誤**：境外一頁式假購物站難起訴 → 網購 M1 被低估。
- **Leg B 樣本** ~325 筆被害人、6 手法分層各 n≈22–71，覆蓋約 58% 的詐欺案件類型；其餘 42% 為定性界定。
- **Leg A** 為供給端（被通報/攔阻者），160055 的 D3 因「自建 vs 無法判定」不可靠而僅報「冒名 vs 非冒名」二分。
- 分類由 LLM agent 執行；信度以雙模型獨立編碼 + κ 檢驗建立，但 P3 全量為單編碼者分層執行（信度承自 P1b 雙編碼 κ）。
