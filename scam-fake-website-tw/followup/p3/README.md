# p3/ — Leg B 需求端編碼（彙總層）

本目錄為 P3 旗艦表的**彙總層輸出**。逐被害人編碼資料依研究倫理不對外公開。

## 為何不公開逐被害人資料

判決書原文在司法院判決書系統上公開可查 —— 但**把多份判決的被害人姓名彙整成可下載的 CSV／markdown，並透過 GitHub Pages 公開索引** —— 與「逐份去司法院系統查閱」性質不同。前者容易被惡意爬蟲索引、聚合、二次利用。為避此風險，逐被害人層級資料留在作者工作區，僅彙總層公開。

## 公開檔案
- `aggregate_p3.py` — 旗艦表 §3.6（手法 × 媒介交叉表）與光譜圖 §F1b 的計算腳本
- `aggregate-p3-output.txt` — 腳本執行輸出，含每手法 × 媒介的人數計數與百分比

## 留在作者工作區（不公開）
- `coding-legb-claude.csv` / `coding-legb-codex.csv` — 雙模型逐被害人編碼
- `legb-victim-index.csv` — Leg B 被害人索引
- `strata/` — 六手法分層 CSV
- `extracts/` — 各份判決逐被害人事實抽取 markdown

## 如何驗證

讀者可從本目錄的 `aggregate-p3-output.txt` 重現論文 §3.6 旗艦表的所有數字 —— 該檔即為論文中所有 per-手法 × per-媒介 計數的直接來源。`aggregate_p3.py` 顯示計算邏輯（如何從 strata CSV 累計到旗艦表），方法論可審計。

如需審查逐被害人層級資料以驗證編碼信度，請聯絡作者並提供研究倫理用途說明。
