### 統一之手法/媒介事實（適用於附表三所有投資人被害人）

- `手法_facts`：「假投資」——虛擬貨幣 AI 自動交易套利吸金。判決原文：「宣稱該計畫係由系統透過AI機器人之量化分析，自動操作虛擬貨幣交易，在全球交易所以低買高賣之方式賺取價差套利……依雲錢包之制度，投入資金可獲得靜態獲利（每月收益為投資金額之6%-12%）……以及動態獲利（透過招攬新投資人加入而獲取，即推薦獎金，有等級、階層制度）」。屬假投資 + 多層次推薦（吸金/類MLM）。

- `媒介_facts`:**核心媒介為「假冒APP」**。判決原文：「雲錢包之投資方式係由投資人下載 Cloud Token、Cloud 2.0 之 APP，輸入推薦人（即上線）之邀請碼後創建帳號，再透過幣商或虛擬貨幣交易所存入單一幣種至少500美元之虛擬貨幣，或現金交付上線取得CTO……待虛擬貨幣儲存成功後，即可在該APP內點選『加入賈維斯（Jarvis AI）計畫』，將虛擬貨幣轉移至雲錢包之特定錢包地址進行賈維斯計畫」。
  - 被害人之損失互動發生在「Cloud Token / Cloud 2.0」這個專屬投資APP（詐騙集團自有的應用程式），以及向上線/幣商交付虛擬貨幣或現金。APP 名稱「Cloud Token」「Cloud 2.0」（雲錢包）為**自創品牌名，非冒充任何真實既有 APP/品牌**。
  - 另有實體說明會、ZOOM 線上會議由 AAI 親自說明（屬觸及/招攬層，非損失互動所在）。
  - 無獨立假網站（URL）的描述；核心為自有 APP。

- `觸及_facts`：多元——⑴ 網路 YouTube 說明/訪問影片招攬全球投資人；⑵ 實體大型發表大會（108/7/21 矽谷國際會議中心「創新技術發表大會」數百至上千人）；⑶ 親友介紹（宇○○經友人寅○○、陳玉慧介紹；戌○○經友人午○○、陳玉慧介紹；辛○○經戌○○介紹）；⑷ Rich創富系統的 LINE 群組（「Rich System核心」「Rich創富C1菁英群」）、微信群組（「Rich創富鐵粉」）密集發布說明會與獲利訊息；⑸ 實體說明會/分享會/講座。多數投資人經由社群推廣 + 熟人介紹 + 說明會接觸。

- `財損`：AAI 共同吸收資金規模至少相當於 NT$4,141 萬 7,939 元；宇○○、劉富緯、林丞萱共同吸收資金規模至少相當於 NT$1,513 萬 3,751 元。逐人金額在附表三（未取得）。
