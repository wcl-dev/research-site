# c024: 165反詐騙諮詢專線_假投資(博弈)網站 (open dataset 160055)

**URL**: https://data.gov.tw/dataset/160055
**Source type**: primary_doc (金品質開放資料集) | **Quality**: qs=5
**Deep-read on**: 2026-05-21（twinkle-hub opendata-get_dataset + 聚合 query_rows）
**Access status**: ok (MCP portal — twinkle-hub)
**Pages/length**: 45,259 列；欄位：WEBSITE_NM(網站名稱)、WEBURL(網址)、CNT(件數)、STA_SDATE(統計起始日期)、STA_EDATE(統計結束日期)

## Directly addresses
- Q3: B 型 — 假投資/假博弈網站逐筆清單與每站被通報件數，B 型規模的官方逐週序列。
- Q6: 「統計起始日期」欄提供 2021-2025 的縱貫趨勢（B 型假投資站的逐年量變）。
- Q1: 提供「假投資詐騙透過獨立假網站運作」的一個分母。

## Key passages

### Passage 1 — for Q6 / Q3（假投資博弈網站逐年趨勢 — 載重數字）
> （Segmenter 聚合，twinkle-hub query_rows，依「統計起始日期」年份）：
> 2021 年 64 列站次、通報件數合計 288；**2022 年 4,135 列、件數 15,950；2023 年 11,391 列、件數 29,526；2024 年 17,306 列、件數 36,755；2025 年 12,362 列、件數 22,315**。

**Page/section**: 全資料集聚合（STA_SDATE 欄）
**Why it matters**: B 型假投資/假博弈網站的官方逐年序列。**逐週公布的假投資博弈網站站次自 2021 的 64 暴增至 2024 高峰 17,306，2025 回落至 12,362**；對應通報件數 2024 高峰 36,755、2025 降至 22,315。這是 Q6 趨勢的核心一手證據：B 型假投資站 2022-2024 急升、2025 出現結構性回落（與 c041 moda「金融投資類詐騙較高峰下降 97%」、c042 廣告掃描數下降在方向上一致）。注意 2025 回落須謹慎解讀 —— 可能是真實下降，也可能是此資料集 2026 起被 176455 取代、2025 後期更新趨緩所致。

### Passage 2 — for Q3（資料集口徑說明 — B 型專屬）
> 資料集 metadata 自述：「提供假投資（博弈）網站資訊。因應刑事警察局目前執行『涉詐網域停止解析』業務，範圍非限縮於原有之假投資或假博奕等詐欺案類，於是另外創建新公開資料集『165反詐騙諮詢專線_遭停止解析涉詐網站』。」

**Page/section**: metadata description
**Why it matters**: 明確界定此資料集口徑 = 假投資 + 假博弈網站，與假投資詐騙（brief 的 B 型主力）高度對應。45,259 列的母體就是「假投資/假博弈站」的逐週清單。此口徑窄但純，是 B 型最乾淨的官方 proxy。

### Passage 3 — for Q3（B 型站的命名特徵 — 自創品牌）
> 樣本列：「0857娛樂城」(www.0857.games)、「0x」(www.0xdappplus.com／www.0xplusdapp.com)、「0xBoost」(www.0xboost.finance)。

**Page/section**: 樣本列
**Why it matters**: 假投資/假博弈站的網站名稱多為**自創品牌**（0857娛樂城、0xBoost…）而非冒充真實對象 —— 佐證此資料集主體是 B 型（非冒名型）。但 c031 法院判決顯示有少數例外是近似冒名真實交易所（BYBITPRO 冒 Bybit）—— 故「假投資站 = 純 B」是近似而非絕對，Drafter 引用須保留此小幅 A 型滲透。

## Structural content worth knowing
- 每列一個站，CNT 欄是該站在該統計週被 165 通報的件數；同一網站名稱可有多個 WEBURL（攻擊者輪換網域），如「0x」對應 0xdappplus.com 與 0xplusdapp.com 兩個網址 —— 顯示 B 型站也有網域輪換/快閃特性。
- 第一列為欄名重複列（"網站名稱","網址","件數"…），聚合查詢已用 WHERE STA_SDATE LIKE '20%' 排除。

## Caveats / limitations
- 此資料集 2026-01 起被 176455（c022）取代，「假投資博弈」窄口徑可能不再更新；2025 數字可能不完整。
- CNT 是「被通報件數」非「受害人數」非「財損」—— 是 supply-side / 通報量指標。
- 站次（列數）≠ 獨立網站數，因同站多網域；真實獨立假投資站數略低於列數。
- 偶有近似冒名真實交易所的列，整體仍以 B 型為主但非 100%。
