# c027: 嘉義市113年詐欺管道與詐欺手法一覽表 (open dataset 52459)

**URL**: https://data.gov.tw/dataset/52459
**Source type**: primary_doc (金品質開放資料集) | **Quality**: qs=4
**Deep-read on**: 2026-05-21（twinkle-hub opendata-get_dataset + 聚合 query_rows）
**Access status**: ok (MCP portal — twinkle-hub)
**Pages/length**: 2,461 列；欄位：統計年份、月份、詐騙管道、詐騙手法

## Directly addresses
- Q7: 罕見同時帶「管道」與「手法」兩維度的官方資料 —— 但證明即使是這個最接近的替代維度，也切不出「假網站」。Q7「現行統計缺什麼」的最佳示例。
- C 軸: 具體呈現「管道 ≠ 媒介」—— 官方的「管道」只到 channel 層級。

## Key passages

### Passage 1 — for Q7 / C 軸（管道維度 — 仍切不出「假網站」）
> （Segmenter 聚合，「詐騙管道」欄）：網路詐騙 2,190（89.0%）、直接與人接觸 111、接獲歹徒電話 100、接獲手機簡訊 36、其他 23、接獲電話語音 1。

**Page/section**: 聚合查詢（詐騙管道欄）
**Why it matters**: 這是 Q7 的關鍵示例。嘉義市是少數在官方統計裡加了「詐騙管道」維度的縣市 —— 但這個「管道」只切到 **channel 層級**（網路詐騙 / 電話 / 簡訊 / 直接接觸），**不是 brief 要的「媒介」層級**（假網站 vs 惡意簡訊連結 vs 假冒 APP vs 社群假廣告）。「網路詐騙」這一格佔 89%，但它把假網站、社群假廣告、真平台假賣場、純 LINE 群組**全部混在一起**。結論：**即使官方願意加管道維度，現行的做法仍無法把「假網站」獨立計數** —— 這正是 Q7「要回答假網站佔比，現行統計缺什麼」的答案：缺的不只是「有沒有管道欄」，而是「管道欄的粒度要細到媒介層」。

### Passage 2 — for Q1（手法分布 — 地方樣本）
> （Segmenter 聚合，「詐騙手法」欄）：假投資 577、假網拍 305、解除分期付款(騙賣家) 231、假交友(投資詐財) 172、中獎通知 150、騙取金融帳戶 140、色情應召詐財 138、假借銀行貸款詐財 89、釣魚簡訊(惡意連結) 56、假廣告 53、假冒機構(公務員)詐財 42。

**Page/section**: 聚合查詢（詐騙手法欄）
**Why it matters**: 嘉義市 2024 年詐欺手法以假投資（577）居首，其次假網拍（305）。把可能用假網站的手法（假投資 + 假網拍 + 假交友投資 + 假借銀行貸款 + 釣魚簡訊 + 假廣告 + 假冒機構）粗加約佔多數。注意「釣魚簡訊(惡意連結)」56 件是獨立手法格 —— 與「假投資」「假網拍」並列，顯示官方有時把「媒介」（釣魚簡訊）和「手法」（假投資）混在同一個分類欄，分類軸本身不一致 —— 又一個 Q7 資料品質問題。

## Structural content worth knowing
- 資料集 2,461 列 = 嘉義市 2024 年逐月、逐案的（管道 × 手法）配對。可做 channel×method 交叉表，但因「管道」粒度太粗，交叉後仍切不出假網站。
- 「詐騙管道」與「詐騙手法」兩欄有時語意重疊（如管道「接獲手機簡訊」vs 手法「釣魚簡訊(惡意連結)」）—— 分類體系未嚴格區分「媒介」與「手法」。

## Caveats / limitations
- 嘉義市單一縣市、2024 單年，地方樣本不可代表全國。
- 此資料集的價值是「Q7 具體示例」——「即使有管道維度也切不出假網站」，不是佔比來源。
- 「管道」分類粒度只到 channel，不到 media；Drafter 應引此說明「替代估計法需要的不只是加欄位，而是加細粒度」。
