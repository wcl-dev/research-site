# c043: 114年詐欺犯罪19.8萬件，詐欺被害人24歲以上皆以「投資詐欺」最多 (警政統計通報)

## Directly addresses
- Q1: 官方「受理案件數」分母 —— 114 年詐欺犯罪約 19.8 萬件，及按手法分類的官方做法。
- Q7: 直接示範 C 軸根因 —— 警政署按「手法/類型」（投資詐欺…）分類，「假網站」不在分類軸上。

## Key passages

### Passage 1 — for Q1（詐欺犯罪案件總數 — 載重分母）
> 「114 年詐欺犯罪計約 19.8 萬件；24 歲以上被害人以『投資詐欺』類型最多。」（警政署統計室，2025 第 14 週統計通報）

**Page/section**: 統計通報標題與列表摘要
**Why it matters**: 19.8 萬件是「受理詐欺犯罪案件數」這個分母的官方權威數字（內政部口徑，2024 全年）。任何「假網站佔比」若以受理案件數為分母，分母就是這個 198,000。注意：與 brief reconnaissance「165 打詐儀表板 2025 全年約 16.2 萬件」是**不同年度、不同口徑**（165 是受理通報、警政統計通報是刑案統計）—— Drafter 必須分清楚這兩個分母。

### Passage 2 — for Q7 / C 軸（官方分類軸 = 手法）
> 統計通報的分類軸是「詐欺類型/手法」：投資詐欺、（網購、解除分期付款、假交友…）。「24 歲以上皆以投資詐欺最多」。

**Page/section**: 統計通報標題
**Why it matters**: 這是 C 軸根因的官方一手證據 —— 警政署的詐欺犯罪統計**按「手法/類型」切**（投資詐欺、網購…），完全沒有「假網站 vs 簡訊 vs 純語音」的媒介軸。「假網站」是橫跨投資詐欺、網購詐欺、釣魚詐騙多個手法類別的工具，因此**不可能**在這套統計裡有一個獨立佔比。Drafter 應引此作為「為何沒有單一官方假網站佔比」的直接證明。

## Structural content worth knowing
- 此 URL 是統計通報的**列表頁**；個別通報全文在 detailNo 子頁（如 detailNo=1488707994689474560），子頁直連回 HTTP 400 anti-bot/session 阻擋。因此各手法的精確佔比百分比（投資詐欺佔 X%、網購佔 Y%）無法從本記錄取得 —— 須由 Drafter 結合 165 儀表板（c046，JS-only）或其他二手報導補。

## Caveats / limitations
- 細頁 HTTP 400：精確的手法佔比百分比表未取得，只有標題層「投資詐欺最多」的定性結論。
- 「詐欺犯罪 19.8 萬件」是刑案統計口徑，與 165 受理通報量、moda 通報量、TWNIC 攔阻量都是不同分母，不可互換或加總。
- 「24 歲以上以投資詐欺最多」是分年齡層的結論，非全體；24 歲以下另有不同主力手法（見 c045）。
