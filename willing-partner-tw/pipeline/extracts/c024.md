## Directly addresses
- Q5 [C4]: this is the **richest confirmed C4 government-channel instance** in this evidence base — a local police unit's own page listing all four Taiwan civil fact-checking organizations by name, with links, plus an independent mechanism description of the LINE integration.

## Key passages

### Passage 1 — for Q5 (all four orgs named, verbatim page title + structure)
> Page title: "高雄市政府警察局刑事警察大隊-事實查核平臺"
> Section header: "事實查核平台" listing, in order: "(一)台灣事實查核中心（Taiwan FactCheck Center；TFC）", "(二)MyGoPen：", officialsite links, "(四)Cofacts真的假的：" (official site: `https://cofacts.g0v.tw/`)

**Why it matters**: A Kaohsiung city police unit's own public-facing page names and links **all four** Taiwan fact-checking organizations (TFC, MyGoPen, 蘭姆酒吐司 [implied as the missing "(三)" per the numbering], Cofacts) as public verification resources — the clearest "government treats civil fact-check orgs as public infrastructure" instance found in this batch, and notably **more complete than c025** (the central-government 調查局 page), which names only two of the four.

### Passage 2 — for Q2/Q5 (LINE mechanism description, independently corroborating c003)
> "LINE官方帳號：@LINE factchecker
> LINE訊息查證與四間查核機構合作，包括台灣事實查核中心、MyGoPen、蘭姆酒吐司、CoFacts 真的假的，讓廣大的 LINE 用戶，只要加入「LINE訊息查證」官方帳號，就可以在 LINE 的對話視窗中，直接將需查證的訊息分享至官方帳號。而在 LINE 訊息查證的官方帳號視窗中，會判讀訊息內容，提供已查證的結果，或是類似的內容，若是資料庫中沒有相關的內容，就可選擇回報查核單位進行查證，不過只支援文字判讀。"

**Why it matters**: This mechanism description is **near-identical in substance** to c003's 2019 description of the same LINE feature (compare: "系統就會自動比對既有資料庫資料判斷其真偽，若訊息內容尚未查核，則會自動提報給專業查核單位" in c003 vs "會判讀訊息內容，提供已查證的結果...若是資料庫中沒有相關的內容，就可選擇回報查核單位進行查證" here) — independent corroboration, from a government source seven years later, that LINE's fact-check-forwarding mechanism has remained structurally stable since 2019. Also notes an explicit **limitation**: "不過只支援文字判讀" (text-only; does not support image/media verification) — a mechanism caveat not present in c003.
